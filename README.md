<h1>Introducing OnTrack!</h1>
<h4>OnTrack is the all in one place for all Amtrak (USA's Rail System) Trains. OnTrack is the American Companion of <a href = "https://bayley.elduquette.com/TrainNow/">TrainNow</a>, the UK Equivalent.</h2>
<h2>Meet the Developer!</h1>
<h4>Hi! I'm Bayley, A twelve year old computer programming student learning about Web Development. I made <a href = "https://bayley.elduquette.com/TrainNow/">TrainNow</a> while living in the UK, and when I moved to the US, I thought it would only make sense to build the same thing for Amtrak! Personally, I have a passion for Public Transportation and use it frequently!</h4>
